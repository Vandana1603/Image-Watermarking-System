# Image-Watermarking-System

This project is a Java-based application that allows users to add a watermark to images.
The system provides features such as watermark text customization, also provides a live preview feature, so users can see how the watermark looks before saving the final image.

Features

 1.Image upload
 
 2.Custom watermark text
 
 3.Font style and size selection

 4.Color selection
 
 5.Live watermark preview
 
 6.Admin can access activity logs

**Technologies Used**

*Programming Language*

Java

*Libraries*

1.Java Swing (GUI)

2.AWT Graphics

3.ImageIO

STEPS TO RUN THE PROJECT

1.Prerequisites

Make sure Java JDK 8 or higher is installed.

2.Compile the Project

Open a terminal inside the project folder and run:

javac WatermarkApp.java WatermarkEngine.java

3.Run the Application

Execute the following command:

java WatermarkApp


The Watermark System GUI will open.
